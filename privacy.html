Privacy policy

gmail-local · last updated 18 November 2026

Who uses the app

gmail-local is a personal tool used only by its owner with the owner's own Google accounts. It is not offered to the public.

What data it accesses

With the owner's consent, the app uses the Gmail API scope gmail.modify to read, search, label, draft and send messages and to read send-as settings in the accounts the owner connects. It cannot permanently delete mail.

How the data is used

Data is used only to carry out actions the owner asks for through the owner's own AI assistants (Claude, Codex). Message content the owner asks about is passed to that assistant to answer the request. Data is not sold, not used for advertising, and not shared with anyone else.

Storage

The app has no servers. OAuth tokens are stored in the macOS Keychain on the owner's computer. Email content is not stored, except attachments the owner explicitly asks to save to their own disk.

Limited Use

gmail-local's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.
